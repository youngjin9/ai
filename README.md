# ⚾ KBO 한국프로야구 정보 대시보드 (KBO Dashboard)

Python과 Streamlit을 기반으로 제작된 **KBO 리그 대시보드 웹 애플리케이션**입니다.  
10개 구단의 순위, 일정 및 경기 결과, 부문별 개인 성적 랭킹, 전국 홈구장 지도 시각화 및 최신 뉴스 피드를 제공합니다.

---

## 🌟 주요 기능
1. **📊 정규리그 순위표**: 10개 구단 승/무/패, 승률, 게임차 및 다승 비교 막대그래프
2. **📅 경기 일정 & 결과**: 날짜별 매치업, 양 팀 스코어, 투수 정보 및 중계 채널 안내
3. **⭐ 개인 성적 랭킹**: 타자(타율, 홈런, 타점, 안타, 도루) 및 투수(평균자책점, 다승, 탈삼진, 세이브, 홀드) TOP 5 랭킹
4. **🏟️ 전국 홈구장 투어**: Folium 기반 인터랙티브 구장 지도 및 구장 간 직선거리 계산기
5. **📰 최신 KBO 뉴스**: 실시간 프로야구 헤드라인 뉴스 피드
6. **🏟️ 10개 구단 상세 프로필**: 구단별 공식 엠블럼, 창단 연도, 통산 우승 횟수 및 공식 홈페이지 연동

---

## 🚀 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 웹 대시보드 실행
```bash
python -m streamlit run web.py
```
또는 Windows 환경에서는 `run_web.bat`을 더블 클릭하여 실행할 수 있습니다.

### 3. 브라우저 접속
브라우저 주소창에 `http://localhost:8501`을 입력하여 접속합니다.

## 🛠️ 기술 스택
- **언어**: Python 3.12+
- **웹 프레임워크**: Streamlit
- **데이터 분석 및 처리**: Pandas, BeautifulSoup4, Requests
- **시각화**: Plotly, Folium, Streamlit-Folium
- **위치 거리 계산**: Geopy
